# API Reference

## Overview

behave-format provides a minimal, focused API:

- **Settings** — Immutable formatter configuration
- **format_project** — Format a behave-model Project in place
- **render_project** — Format and render a Project as text
- **format_feature** — Format a single Feature in place
- **render_feature** — Format and render a Feature as text
